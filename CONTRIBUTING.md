# Contributing to CodeForge

## Development Principles

1. **One step at a time** - Each feature must be complete before moving forward
2. **Test everything** - No code without tests
3. **Document as you build** - Every module needs clear documentation
4. **SOLID principles** - Keep code clean and maintainable

## Getting Started

1. Fork the repository
2. Create a feature branch: `git checkout -b feature/your-feature`
3. Make your changes
4. Write tests
5. Submit a pull request

## Commit Convention

We use conventional commits:
- `feat:` New feature
- `fix:` Bug fix
- `docs:` Documentation
- `test:` Adding tests
- `refactor:` Code restructuring

## Questions?

Open an issue or start a discussion.
