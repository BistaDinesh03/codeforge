## Quick Install

### Windows
1. **Download** [CodeForge-Setup.exe](https://github.com/codeforge/codeforge/releases/latest)
2. **Double-click** to install
3. **Click "Start Server"** on your desktop

That's it. Open VS Code, install the extension, it auto-connects.
