# CodeForge

Turn your Android phone into a private AI coding server for VS Code.

## What is CodeForge?

CodeForge transforms your Android device into a personal, offline AI coding assistant that integrates directly with VS Code. No cloud dependencies, no subscription fees, no data leaving your device.

## Architecture

- **VS Code Extension**: Seamless integration with your editor
- **Python Backend**: FastAPI server handling AI requests
- **llama.cpp**: Efficient local model inference
- **Android via Termux**: Your phone becomes the server
- **ADB Communication**: Secure USB bridge between devices
