## What is CodeForge?

CodeForge runs AI on your own computer. VS Code connects to it. Your code never leaves your machine.

**Like GitHub Copilot, but you own it. Free. Private. Offline.**

---

## Quick Start

### Windows
1. Download `CodeForge-Setup.exe`
2. Double-click → Install
3. Click "Start Server" on desktop
4. Install VS Code extension
5. Extension auto-connects. Done.

### Linux / macOS
```bash
curl -sL https://raw.githubusercontent.com/codeforge/codeforge/main/installer/install.sh | bash

Troubleshooting
Server won't start? Check if port 8000 is in use.
Extension can't connect? Both computers on same network? Firewall blocking port 8000?
Model slow? Try a smaller model. Close other apps.
