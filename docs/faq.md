# FAQ

## Basics
**Q: What is CodeForge?**
A private AI coding assistant that runs on your computer. Like Copilot, but free and offline.

**Q: Is it really free?**
Yes. MIT license. No paid version. No subscriptions.

**Q: Do I need internet?**
Only to download the AI model once. After that, works fully offline.

## Setup
**Q: What do I need?**
A computer with 4GB+ RAM and Python 3.11+. Works on Windows, Linux, macOS.

**Q: How long does setup take?**
About 3 minutes. Download EXE, double-click, wait, done.

**Q: Can I use it on my work computer?**
Yes. MIT license allows any use, including commercial.

## Usage
**Q: How do I get completions?**
Just type. Ghost text appears. Tab to accept.

**Q: Can I use my own AI model?**
Yes. Any GGUF model. Put it in the `models/` folder.

**Q: Why is it slower than Copilot?**
Copilot uses cloud GPUs. CodeForge uses your local CPU. It's the tradeoff for privacy.

## Privacy
**Q: Does my code leave my computer?**
No. Everything runs locally. Zero data collection.

**Q: Can you see my code?**
No. We have no servers. We can't see anything.
