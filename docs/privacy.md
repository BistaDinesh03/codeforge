# Privacy

## What CodeForge Does
- Runs entirely on your computer
- AI model runs locally
- Your code never leaves your machine

## What CodeForge Does NOT Do
- No cloud servers
- No telemetry
- No usage tracking
- No data collection
- No internet needed (after model download)

## Open Source
Every line of code is public at [github.com/codeforge/codeforge](https://github.com/codeforge/codeforge). You can verify there's no tracking.

## Network
- Server binds to `0.0.0.0` to accept connections from your local network
- Only devices on your WiFi can connect
- Set `API_KEY` in `.env` to add a password
