# Quick Start Guide

## 5 Minutes to Your Own AI Coding Assistant

### Step 1: Download
Go to [GitHub Releases](https://github.com/codeforge/codeforge/releases) and download `CodeForge-Setup.exe`

### Step 2: Install
Double-click the file. Click "Install". Wait 2-3 minutes.

### Step 3: Start
Double-click "CodeForge Server" on your desktop. A window opens with "Server running".

### Step 4: Install VS Code Extension
Open VS Code → Extensions (Ctrl+Shift+X) → Search "CodeForge" → Install

### Step 5: You're Done!
The extension connects automatically. Start typing code — ghost text appears. Press Tab to accept.
