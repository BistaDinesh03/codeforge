# Changelog

## v1.0.0 (2026-07-31)

### Features
- Inline code completions (ghost text)
- Streaming chat responses
- Code rewrite with diff preview
- Project indexing with BM25 search
- Auto-discovery on local network
- Windows installer (double-click)
- Auto-updater with rollback
- Rate limiting
- Multiple model support

### Backend
- FastAPI server with 7 API modules
- Model manager (load/unload/switch)
- Health diagnostics endpoint
- Structured logging with rotation

### Extension
- Modern chat panel UI
- Status bar indicator
- Right-click code actions
- Auto-reconnect

### Tests
- 47 backend tests
- Extension test suite
